# 2026 천안시 청년정책 — 웹 프레젠테이션

첨부된 10장 PPTX의 슬라이드 디자인을 이미지로 그대로 유지하고 탐색 및 인터랙션을 구현한 정적 웹사이트입니다.

## 실행

- `index.html`을 브라우저에서 열면 됩니다. 인터넷 연결이나 별도 서버가 필요하지 않습니다(출처 링크를 열 때만 인터넷 필요).
- GitHub Pages: 이 폴더의 `index.html`, `assets/` 디렉터리를 저장소 루트에 그대로 업로드하고 **Settings → Pages → Deploy from a branch → main / root**를 선택하세요.
- 브라우저 단축키: ←/→, PageUp/PageDown, Home/End, F(전체화면), G(전체 보기), Esc(닫기). 슬라이드에서 터치 좌우 스와이프 및 휠 이동 지원.
- 슬라이드별 직접 연결: `index.html#slide-5` 형태.

## 원본 충실도 및 편집

- `assets/slide-01.jpg`~`slide-10.jpg`는 원본 PPTX를 PDF로 렌더링 후 웹용 이미지로 변환했습니다. 차트, 인물 이미지, 텍스트 등 원본의 모든 시각 요소는 각 슬라이드에 포함됩니다.
- `index.html` 안의 `slides` 배열은 각 페이지의 텍스트 접근성, 상세 설명, 원본 발표자료 출처 링크를 제공합니다.
- 슬라이드 본문의 개별 텍스트/차트 요소는 원본 화면의 정확한 보존을 위해 하나의 슬라이드 이미지로 제공되므로 웹에서 개별 편집되지는 않습니다. 화면 자체에 개별 요소 애니메이션이 적용되지는 않으며 슬라이드 단위 전환이 적용됩니다.
- 정책 수치는 원본 PPTX에 기재된 값을 옮겼으며 신규 통계 검증이나 추가 조사 결과를 의미하지 않습니다.
